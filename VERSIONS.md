## Release workflow
1. Download the live Blogger XML before editing.
2. Keep the last release backup unchanged.
3. Edit a working copy and validate XML.
4. Test Blogger preview, mobile and desktop.
5. Update the changelog and API register.
6. Save the exact deployed XML as a new versioned backup.
7. Create a Git commit, tag and GitHub release.
